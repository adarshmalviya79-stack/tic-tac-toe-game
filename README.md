Tic-Tac-Toe Game – Description

Tic-Tac-Toe, also known as Noughts and Crosses, is a classic two-player strategy game played on a 3 × 3 grid. It is one of the simplest and most popular logic games because of its easy rules and quick gameplay.

🧑‍🤝‍🧑 Players

Player 1: Uses symbol “X”

Player 2: Uses symbol “O”

Both players take turns marking empty cells in the grid.

🎯 Objective

The main goal is to be the first player who forms a straight line of three identical symbols (either X or O).
This winning line can be:

Horizontal (across a row)

Vertical (down a column)

Diagonal (corner to opposite corner)

📌 How the Game Works

The game starts with an empty 3×3 board.

Players take turns placing their symbols (X or O) in any available empty cell.

After every move, the game checks for a winning condition.

If a player forms a line of three of their symbols, they win the game.

If all 9 cells are filled and neither player wins, the match ends in a draw.

🏆 Winning Conditions

A player wins if they make any one of these combinations:

Rows:
[0,1,2], [3,4,5], [6,7,8]

Columns:
[0,3,6], [1,4,7], [2,5,8]

Diagonals:
[0,4,8], [2,4,6]

💡 Game Features (Common in JavaScript version)

Click a cell to place X or O

Turns alternate automatically

Game detects winner

Draw condition when board is full

Reset button to play again
